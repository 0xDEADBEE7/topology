Topo is built for progressive inspection: start with the repository shape, narrow to a file or symbol, and read implementation details only when they matter.

---

## Quickstart

Build the CLI and inspect the current project:

```bash
cargo build --release
target/release/topo .
target/release/topo ./src
```

Find a definition or inspect one symbol:

```bash
target/release/topo find analyse
target/release/topo ./src/metrics.rs::compute
```

Run the checks used during development:

```bash
cargo test --quiet
cargo check --quiet
```
