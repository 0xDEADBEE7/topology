---

topo maps a repository's shape and rates its functions, so a person or an agent can read
the smallest part of a codebase that answers a question. It parses Rust, Python,
TypeScript, TSX and JavaScript with tree-sitter, runs nothing from the project, and stays
small itself: about 1,400 lines of Rust in nine files, all of them green on its own score.

## Install

```bash
cargo install --path .        # or: cargo build --release, then target/release/topo
```

It needs Rust 1.90 or newer, and git for `.gitignore`-aware discovery (without git, topo
walks the directories).

## Read a repository from the top down

A directory shows its files with their descriptions:

```console
$ topo tests/fixtures/typescript
typescript/
├─ basic.ts
├─ components.tsx  #─── Renders a conditional greeting.
├─ declarations.ts  #── Declares functions with docs, headers and exports.
├─ ranges.tsx  #─────── Pins where units start, what they are named and whi...
└─ semantics.tsx  #──── Exercises component naming, callback folding, and c...
```

A file shows its declarations, their line ranges and descriptions, without the source:

```console
$ topo tests/fixtures/typescript/declarations.ts
tests/fixtures/typescript/declarations.ts  #── Declares functions with docs...
  add (L11–13)  #────────────────── Adds two numbers.
  tagged (L16–18)
  local (L21–21)
  Counter (L23–35)
    Counter.increment (L25–27)  #── Increments the count.
    Counter.reset (L32–34)  #────── Resets the count.
  click (L39–39)  #──────────────── Handles a click.
  other (L45–45)
  footer (L48–48)  #─────────────── Renders the copyright footer.
  legacy (L55–55)
  internal (L60–60)
  Store (L62–67)
    Store.handle (L64–65)  #─────── Handles a click.
    Store.onKey (L66–66)
  home (L69–69)
  about (L69–69)
  user (L73–74)  #───────────────── Loads the user.
  wrapper (L77–80)
    local (L78–78)
```

`file::name` shows one declaration's source:

```console
$ topo tests/fixtures/typescript/declarations.ts::add
tests/fixtures/typescript/declarations.ts::add (L11–13)
export function add(a: number, b: number): number {
  return a + b;
}
```

`find` lists where a name is declared, in a form to pass back to topo:

```console
$ topo find increment tests/fixtures
2 matches for 'increment':
tests/fixtures/typescript/declarations.ts::Counter.increment [function] (L25–27)
tests/fixtures/typescript/semantics.tsx::Store.increment [function] (L25–27)
```

## Rate functions

yellow and red ones under their files (`--detail` lists every function). Tests and stories
found by a scan are left out unless `--tests` is given.

## Development

`make check` runs rustfmt, Clippy with warnings denied, the tests, and every command in this
README, comparing its output with what is shown here. The tests also hold topo to its own
standard: every source file has a module doc, at most 400 code lines and no parse errors;
no function is yellow or red; and `src` stays within 9 files, the line budget in
`tests/cli.rs` and 5 dependencies. The budgets only go down: when topo fails them, the code
is simplified, never the limit raised.

`.scripts/corpus.sh` checks behaviour on six real repositories pinned to fixed commits
(excalidraw, zustand, bulletproof-react, docusaurus, requests and ripgrep): `fetch` clones
them into `.local/corpus`, `run BIN OUT` records extract, score and tree output with a
summary line per repository, and `diff A B` lists the files whose records changed between
two binaries (`IGNORE='del(.field)'` drops fields first).
